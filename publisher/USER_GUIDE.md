# 哆嗒内容工作台 · Windows 绿色版

## 第一次使用

1. 把压缩包完整解压到一个可写目录，双击 `DuodaaPublisher.exe`。无需安装 Python、Node 或编辑器，Git 不包含在包内。
2. 打开“网站设置”，选择**网站内容的主文件夹**，例如 `D:\我的网站\duodaa_web`。这里选的是网站目录，不是 Git 程序目录。目录中应有 `blog/articles`、`blog/index.html` 和网站的 Git 仓库。
3. 检查网站域名、网站名称和默认作者。Git 默认自动查找电脑中已有的程序；仅找不到时才需在高级设置中填写 `git.exe`。
4. 在电脑已有的 Git 中完成远程仓库访问配置。工具使用现有 Git 身份、SSH 密钥或凭据管理器，不保存 GitHub 密码或访问令牌。

界面使用电脑自带的 Edge 或已有 Chrome 打开独立应用窗口；没有这两种浏览器时会使用默认浏览器。编辑、草稿与 AMP 校验均可离线使用，导入微信文章和 Git 推送需要联网。

## 编写和更新文章

- 点击“新建文章”，填写标题和正文。工具栏支持标题、字体、字号、颜色、背景色、粗体、列表、对齐、行距、链接和公式。
- 点击“图片”选择本机图片，也可以粘贴或拖入图片。点击正文中的图片，可以拖动右下角手柄、输入像素宽度、设置对齐和图片说明。发布时保持比例，并适配手机宽度。
- “导入微信文章”接受 `https://mp.weixin.qq.com/s/...` 链接，获取标题、作者、正文及图片到编辑区。微信返回验证码、访问限制或失效页面时会明确提示；可在浏览器打开原文，再复制正文到编辑区。不会绕过微信验证。
- 左侧“已发布”可以重新打开 `blog/articles` 中的文章并修改，不会生成重复文章。文章已被其他操作修改时，工具会要求重新载入。
- 正文会自动保存为本地草稿，`Ctrl+S` 可立即保存。“本地草稿”可恢复未发布内容。
- LaTeX 公式在编辑区和布局预览中显示源码，正式 AMP 页面使用公式组件排版。

## 上传并发布

点击“预览”可检查桌面和手机布局。点击“上传并发布”会依次：

1. 在工具的临时目录中生成文章，保存并去重图片。
2. 更新博客首页摘要、近期文章列表、归档、所有近期文章的上一篇／下一篇按钮、SEO 信息与 `sitemap.xml`。
3. 使用随工具提供的官方 AMP 校验器检查所有待更新 HTML；校验失败时不写入网站。
4. 检查所选目录的 Git 状态及远程分支，写入文件，只提交本次生成的路径，然后推送当前分支。

新文章保存到 `网站主文件夹/blog/articles/日期时间-编号/index.html`，图片保存在 `assets/images`，可再次编辑的正文源文件保存在 `content/articles`。

网站工作区有其他未提交改动时，请先处理这些改动。远程有新的提交时，先同步再重新载入文章；工具不自动强制推送或解决冲突。推送会包括当前分支此前尚未推送的本地提交。

创建本地提交之前失败，会恢复工具写入的文件；本地提交已经成功但推送失败时，保留文章和提交，在“发布记录”中点击“重试推送”，不会重复创建文章或重复提交。GitHub 推送成功不代表托管平台的部署已完成，可稍后访问网站确认。

## 换电脑或换文件夹

复制整个工具文件夹后，在另一台电脑上打开“网站设置”，重新选择那台电脑的网站主文件夹即可。目录位置没有写死。原目录不存在时，启动后会提示重新选择。

`data` 文件夹与 EXE 放在同一目录，保存设置、草稿、导入图片、预览、发布记录及恢复备份。更换工具版本前可保留该目录；不要只复制 EXE 后删除原来的 `data`。草稿按网站目录区分。若需要迁移某篇草稿，可以先在原配置下打开草稿并复制正文，或保留其 JSON 与图片备份。

关闭窗口后，后台服务会在约 2–3 分钟无活动时退出；也可点击左下角“退出工具”立即退出。应用只监听本机地址，不开放局域网访问。

## 常见问题

- **未找到 Git**：确认本机已有 Git，或在高级设置里指定它的 `git.exe`。
- **需要姓名和邮箱**：在高级设置中填写 Git 提交姓名和邮箱，仅用于本工具的提交，不改全局配置。
- **SSH / HTTPS 身份验证失败**：在本机 Git 中先验证远程仓库访问，再到发布记录重试。
- **导入图片失败**：确认原文可访问。导入不会悄悄丢弃下载失败的图片。
- **上次发布异常中断**：不要删除 `data/jobs` 内的备份，先检查网站 Git 状态和发布记录。确认没有发布进程后，才可移除 `.git/duodaa-publisher.lock`。

本版本适配当前哆嗒网站的 AMP 目录结构。选择其他位置的同类网站仓库时，可配置域名、站名、广告 ID 和远程名称；并非任意静态网站模板的通用转换器。
